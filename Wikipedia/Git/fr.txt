Git est un logiciel de gestion de versions décentralisé. C'est un logiciel libre
et gratuit, créé en 2005 par Linus Torvalds, auteur du noyau Linux, et distribué
selon les termes de la licence publique générale GNU version 2. Git est maintenu
par Junio C Hamano depuis juillet 2005.

Depuis les années 2010, il s’agit du logiciel de gestion de versions le plus
populaire dans le développement logiciel et web, qui est utilisé par 12 millions
de personnes, sur tous les environnements (Windows, Mac, Linux). Git est aussi
le système à la base du célèbre site web GitHub, le plus important hébergeur de
code informatique.
